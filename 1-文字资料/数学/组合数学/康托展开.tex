\textbf{康托展开 (Cantor Expansion)}

\textbf{定义}
给定 $1..n$ 的排列 $p$，其字典序序号（0-based）为
\[
\mathrm{rank}(p) = \sum_{i=1}^{n} a_i (n-i)!,
\]
其中 $a_i = |\{j : j > i,\ p_j < p_i\}|$，即第 $i$ 位之后值比 $p_i$ 小的元素个数（等价于逐位删除 $p_i$ 后，剩余元素中比 $p_i$ 小的个数）。

\textbf{逆康托展开}
给定序号 $\mathrm{rank}$，逐位还原排列：
第 $i$ 位取剩余元素中第 $k+1$ 小，其中 $k = \left\lfloor \mathrm{rank} / (n-i)! \right\rfloor$，随后 $\mathrm{rank} \leftarrow \mathrm{rank} \bmod (n-i)!$。

\textbf{算法}
\begin{itemize}
    \item 双向均需阶乘 $0!, 1!, \ldots, n!$，预处理 $O(n)$。
    \item 正向：树状数组维护值域 $1..n$ 的计数，初值全 $1$；每步 $a_i = \mathrm{sum}(p_i-1)$，再删去 $p_i$。
    \item 逆向：树状数组二分第 $k$ 小（kth）；取走对应元素。
    \item 复杂度 $O(n \log n)$，空间 $O(n)$。
\end{itemize}

\textbf{条件与注意}
\begin{itemize}
    \item 序号满足 $0 \le \mathrm{rank} < n!$；$n$ 较大时序号超出机器整型，需高精度或取模。
    \item 升序排列序号为 $0$，降序排列序号为 $n!-1$。
    \item 0-based 排列 $\{0,\ldots,n-1\}$ 与 1-based 排列 $\{1,\ldots,n\}$ 公式一致（整体平移不改变大小关系）。
\end{itemize}

\textbf{含重复元素的推广}
设第 $i$ 位处理前各值 $j$ 的剩余个数为 $c_j$，则该位贡献为
\[
\frac{(n-i)!}{\prod_j c_j!} \cdot \sum_{v < p_i} c_v,
\]
即原公式将 $a_i$ 换为「小于 $p_i$ 的剩余元素总数」，再乘以该步多重集排列数的分母修正；实现需模逆与值域前缀和。当所有 $c_j=1$ 时退化为基本康托展开。
